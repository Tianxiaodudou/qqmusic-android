# QQ音乐播放器（安卓）

完全独立运行的 QQ 音乐**播放器**：登录、搜索、歌单、推荐、播放（含无损解密）、逐字歌词，全部在设备上完成，不依赖任何服务器。

> 这一版把项目的重心从「下载器」改成了「播放器」：播放页按「顶栏 / 滚动歌词 / 工具栏 / 进度与控制」四层重做，弹层全部从底部滑出且不打断播放。下载能力保留，收进「我的 → 下载管理」。

## 安装

从 [Releases](https://github.com/Tianxiaodudou/qqmusic-android/releases) 下载 `*-qqmusic-player.apk` 直接安装（Android 8.0+）。

固定签名，新版本可直接覆盖安装，不需要卸载。

## 播放页

- **顶栏**：返回、歌名 + 演唱家（长文本中间省略）、更多；睡眠定时激活时显示月亮 + 倒计时。
- **歌词区**（上方 2/3）：小封面低不透明度缓慢旋转；当前句逐字染色、上下相邻句渐小渐暗；自动跟随、手动滚动让位并出现「回到当前」、点击跳句、长按复制/分享；无歌词时可手动加载。
- **工具栏**：收藏 / 加到歌单 / 音质 / 歌词同步；偏移非零时显示 `+0.3s` 与角标。
- **进度条**：细轨道 + 拖动放大手柄；拖动时歌词实时跳到对应句预览，松手才 seek。
- **播放控制**：循环 / 单曲 / 随机，上一首、暂停播放（中央主题色大圆）、下一首、播放列表。
- **底部弹层**：音质、歌词同步（±5s / 0.1s 步进 / 单曲独立）、播放队列、更多菜单（分享、歌曲信息、查看专辑/歌手、均衡器、倍速、睡眠定时、歌词样式、反馈、关于）。

## 命名区分

- **歌词同步**（工具栏）：纠错用的**时间偏移**，±5 秒，按单曲独立记忆。
- **歌词样式**（更多菜单）：字体大小、对齐方式、翻译/音译开关，全局偏好。
- **音质**（工具栏）：文件码率（标准 / 高品质 / 无损）。
- **均衡器**（更多菜单）：声音风格，与音质无关。

## 功能

- **登录**：QQ 扫码 / 微信扫码 / 手机验证码，登录态本地持久化
- **首页**：胶囊入口墙 + 为你推荐信息流；推荐歌单、新歌速递、每日推荐、新碟上架、热门歌手、热搜榜、排行榜、猜你喜欢
- **搜索**：按歌名 / 歌手 / 专辑搜索
- **歌单**：我的歌单、我喜欢、收藏到我喜欢、加单曲到歌单、新建歌单、收藏他人歌单
- **多选**：任意歌曲列表支持长按进多选 / 全选 / 反选，批量加入播放队列、收藏到歌单、下载
- **我的**：头像、昵称、会员类型、会员等级、会员剩余天数、听歌等级
- **设置**：付费单曲/数字专辑在列表里的处理（置灰不可选 / 直接隐藏，已购买的正常显示）；检查更新（内置下载器下载 APK 并拉起安装）；关于
- **播放**：标准 / 高品质 / 无损三档，无损走 QMC2 解密并缓存；播放队列、播放模式、倍速、均衡器、睡眠定时
- **歌词**：QRC 逐字歌词（QQ 自有的 3DES 变体），逐帧平滑扫字（不是一跳一跳），无逐字时回退整行 LRC，带翻译与音译
- **下载**：系统文件选择器选目录（SAF），写入标签 / 封面 / 歌词，下载历史

## 构建

CI 在推 tag 时自动构建并发布 Release。

本地构建需要 JDK 17 + Android SDK 36：

```bash
cd android
gradle assembleRelease -PappVersion=1.23.0
```

签名通过环境变量注入（`ANDROID_KEYSTORE_PATH` / `ANDROID_KEYSTORE_PASSWORD` / `ANDROID_KEY_ALIAS` / `ANDROID_KEY_PASSWORD`），未设置时回退 debug 签名。

单元测试（3DES 移植与参考实现对拍）：

```bash
cd android && gradle testDebugUnitTest -PappVersion=1.23.0
```

## 目录

- `android/` —— Kotlin + Jetpack Compose 工程
  - `net/` —— QQ 音乐接口、歌词、QMC2 解密、登录、下载
  - `player/` —— 全局播放器（队列 / 音质 / 模式 / 倍速 / 睡眠定时 / 均衡器 / 收藏）
  - `ui/player/` —— 播放页：歌词区、底部弹层
- `.github/workflows/build-apk.yml` —— 打 tag 即出包并发布 Release
